## Summary
IN PROGRESS. The broker hub now sits inside Copilot Settings and leads the onboarding Portfolio
step; the standalone Broker connections page renders the same components. A user can see their
broker accounts, sync, reconnect and remove them, connect a broker that the server reports as
connectable, and upload a broker's holdings file (.xlsx / .xls / .csv) where it cannot be
connected. The screens read the live backend contract merged in PR #206. All evidence here is
Playwright against mocked APIs; no request reached staging or a broker.
