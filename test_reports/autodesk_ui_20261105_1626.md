## Findings while building (fixed here unless stated)
1. Agent status: a failed/escalated task's DEGRADED was overwritten by IDLE in a `finally` → the "agents healthy" readout
   could never show a problem. Fixed + test.
2. Header pill counted every registered version of an agent. Fixed (newest version per agent) + AD-UI-07b.
3. Clock formatter ignored numeric timestamps ("— IST"). Fixed (caught by AD-UI-05).
4. NOT fixed (backend gaps, for a follow-up): `GET /events`, `GET /desk/workflows` and `/simulations/{id}/timeline`
   list oldest-first with a LIMIT (newest rows fall off as data grows); `GET /agents/{key}/activity` has no desk-only
   filter (simulation tasks can crowd out desk tasks); no list endpoint for risk assessments; many simulation events
   have no sim_time; `speed`/ACCELERATED changes nothing in the simulator; the engine applies only the account policy
   (no merge of tenant/strategy/segment levels). The screens work around these without inventing data.
5. NOT fixed (UI): crossing the 760 px phone/desktop breakpoint remounts the screen (local filters reset).
