Seven foundations sit under these screens — build once, unblock many

Most “New” screens can’t ship in isolation; they ride shared plumbing. Two are internal and de-risk the most work now (Scheduler, WORM audit); two are the big vendor-gated keystones (order gateway, KYC rail).

Scheduler / Alert Dispatcher internal
Daily jobs + triggered notifications → drift, underperformer, SIP-bounce, review reminders.
Comms Dispatcher email int · SMS/WA vendor
Email/SMS/WhatsApp/push, delivery status, TRAI-DND opt-out. Unblocks WF-07 + all alerts.
MF Order Gateway BSE STAR / MFU
The transactional core — all order/SIP/redeem types, cut-off, MPIN/2FA, retry.
KYC / Onboarding Rail UIDAI · ESP · NPCI · KRA
eKYC + eSign + eMandate + KRA/CKYC via an ESP. Feeds the whole onboarding pipeline.
WORM Audit + Fail-closed internal
Tamper-evident event log, holds txn on write-fail. Pattern already proven in ingestion.
Consent / Disclosure Layer internal
SEBI RDD/KIM/COI acknowledgements — extends the live DPDP consent ledger.
Branding / White-label Config internal
Logo/colour/tagline (custom domain later) — reused by reports, goal PDFs, comms.
