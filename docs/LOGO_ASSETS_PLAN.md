# Plan: company, fund-house and broker logos

Status: **plan for a later phase — nothing in it is built.** Written 2026-10-14.

## Where things stand

- The Copilot app shows an icon beside every stock, mutual-fund and broker name
  (`frontend-v5/src/pages/CopilotApp/components/EntityIcon.tsx`).
- The repository has no logo files and no API returns a logo URL, so every icon is a
  lettered tile today: the name's short code on a colour that is always the same for that name.
- The slot for real logos already exists: `frontend-v5/src/pages/CopilotApp/lib/logo-manifest.ts`
  maps a key (NSE symbol, fund-house name, broker name) to a file. A registered file replaces
  the tile everywhere; if the image fails to load, the tile comes back. Unregistered names cost
  no network request.

So this plan is about **sourcing and serving the files**, not about changing screens.

## What is needed

| Kind | How many | Key | Notes |
|---|---|---|---|
| Brokers | about 20 (the list from `GET /api/broker/native/supported`) | broker slug | Smallest set; five matter first: Zerodha, Upstox, Angel One, Groww, ICICI Direct |
| Fund houses | about 45 AMCs | fund-house name as `fundHouseOf()` returns it | One logo covers every scheme of the house |
| Companies | 2,469 stocks in the feature store; about 500 cover most holdings and screens | NSE symbol | Start with Nifty 500, then fill by how often a symbol is shown |

## Options for the source

| Option | What it is | For | Against |
|---|---|---|---|
| A. Licensed logo service | A paid API or bulk licence for company logos by ticker or domain | Fast coverage of listed companies; updates when brands change | Recurring cost; Indian small-caps and AMCs are often thin; terms may forbid storing copies |
| B. Asset pack we assemble | Download each logo once from the owner's official brand or media page, store it ourselves | Full control; no third party at view time; one-off effort | Manual work (brokers and AMCs are a day; 500 companies is a week); needs a refresh routine |
| C. A data vendor we already pay | Ask Trendlyne (or the exchange data vendor) whether logo use is included in the existing agreement | No new vendor | Unknown until asked; their server exposes no logo field today |

**Recommendation:** B for brokers and fund houses now (about 65 files, done in a day or two), and
ask about C before paying for A for companies. Whatever the source, **serve the files from our
own domain**: a logo requested straight from a third party's server for each stock on a
holdings screen would tell that third party which stocks a user holds.

## Things the owner must decide or check

1. **Permission.** Logos are trademarks. Showing a company's logo beside its name to identify it
   is common practice, but it is the owner's call and each source's terms apply; brokers and AMCs
   usually publish brand guidelines (clear space, no recolouring). This is not legal advice —
   confirm with counsel before launch.
2. **Budget** for option A, if chosen, and whether its licence allows storing copies.
3. **Who maintains** the set when a brand changes or a company lists.

## Technical design (once files exist)

- **Storage:** `frontend-v5/public/logos/{stock,fund-house,broker}/<key>.svg` for the first 65
  files (shipped with the app). For hundreds of company logos, a bucket or the app server's
  static folder under the same site, so the app bundle does not grow; the manifest then holds
  URLs instead of bundled paths.
- **Format:** SVG where the owner publishes one; otherwise a square PNG at 128 px (shown at
  22–40 px). One file per brand that reads on both the dark and the light theme, or a pair
  (`<key>.svg`, `<key>.dark.svg`) with the manifest choosing by theme.
- **Manifest:** generated by a script from the folder listing (`scripts/build-logo-manifest`),
  not edited by hand, so a file that is added is picked up and a typo cannot register a missing file.
- **Keys:** stocks by NSE symbol in upper case; fund houses by the name `fundHouseOf()` returns;
  brokers by the slug the broker list returns. A symbol change (corporate action) needs an alias map.
- **Fallback:** unchanged — the lettered tile.
- **Shared widget:** the screener results inside chat answers are drawn by the shared
  `ChatWidget`, which has no icon yet. Move `EntityIcon` and the manifest to
  `src/components/shared/` and use them there (noted in the round-3 report).
