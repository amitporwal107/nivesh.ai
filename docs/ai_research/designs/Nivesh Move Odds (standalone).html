Rules this screen keeps

  • Invited accounts only. The screen and its API sit behind the move_odds allowlist flag. Anyone else never sees the rail icon, and a direct request gets a 403.
  • Estimates, not calls. No rank numbers, no cut to a short list, no medals, and no green for up or red for down. The full scored list is sorted by estimate.
  • The base rate is always beside the number. Each tab carries it, and every row's track marks it with a tick on a fixed 0–100% scale, never scaled to the largest value.
  • The disclaimer sits above the numbers and never collapses.
  • Inputs on record are the same six for every stock, each with its data date, so no row implies which input mattered.
  • Events are context, not model inputs. Exchange and regulator titles show verbatim. Media items show only source, time and classified type, because 7 of tonight's 641 headlines carry advice language.

States

  • Final. Frozen after NSE's closing file and the 20:30 results window, usually by 21:00 IST.
  • Provisional. From 15:15 prices, labelled in amber and replaced wholesale by the final run. On 17 Sep the two agreed on 9 of the first 10 names for +5%, with rank correlation 0.994.
  • Loading, not published yet, withheld when the closing file fails the row-count check, and no access. None of these shows an earlier session's numbers.

What building it needs

  • API through DaaS: latest estimates by head, one stock's detail with inputs and events, and the model card with band record.
  • V5: a third Research screen, a fail-closed feature guard, and the flag on the rail and the mobile tab bar.
  • A provisional 15:15 run as a scheduled job. Today it exists only as the manual preview from 16 Sep.
  • A live record job that grades each session after the close and fills the band table's live column.

Open decisions

  • A "top 3" view conflicts with the recorded rule of no short-list cut. The sorted list's first rows show the same stocks.
  • Who is invited: internal, advisors or retail (NI-2b).
  • Whether admins bypass the allowlist (UX-2). Proposed: no.
  • Whether the provisional state ships at all. It helps intraday use but doubles what a reader must keep apart.
  • Which model the page shows if the nightly-refit challenger passes its locked test.
