## BUG-2026-006
**Title:** NIDP services emit `Unclosed client session` / `Unclosed connector` ERROR logs on exit  
**Priority:** P3  
**Status:** Fixed  
**Application:** NIDP Console  
**Frequency:** 2 ERROR entries per NIDP service run (fii_dii, event_calendar, etc.)  
**Business Impact:** Pollutes Cloud Logging with spurious ERRORs; inflates `job-failure-count` metric via `severity=ERROR` fallback filter

**Root Cause:**  
`nse_fetcher` maintains a singleton `aiohttp.ClientSession`. Service `__main__.py` files call `close_pool()` at shutdown but never call `nse_fetcher.close()`, so `asyncio.run()` cleanup emits warnings that Ops Agent forwards as ERROR-severity entries.

**Fix:**  
Added `nse_fetcher.close()` call inside `close_pool()` — since both are always torn down together at process exit, this avoids editing every `__main__.py`.  
File: `backend/nidp/shared/storage/pg.py`

**Tests Added:** `qa/test_nidp_clean_session_teardown.py`
